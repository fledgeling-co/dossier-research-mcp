# Deep research

Reports produced by Dossier itself and kept because a feature depends on them.

A run lives in the store at `~/.dossier-research-mcp` and is read with
`research_read { runId }`. Export one here with `research_export` when a feature
brief needs it, so the pipeline can point an agent at a file rather than at a
run id that only exists on one machine.
